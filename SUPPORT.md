# Support and Plans

Contact **[ravitheja.vkota@replayguard.in](mailto:ravitheja.vkota@replayguard.in)** for installation assistance, feedback, evaluation and paid plans.

Include the release version, host OS/architecture, Docker/Compose versions, a short description and redacted error text. Never attach your `.env`, license token, signing keys, Kafka credentials, truststore passwords, full customer payloads or unredacted logs.

Community support is best effort; no response-time or availability SLA is promised. Paid support scope and commercial limits require a separate agreement. Evaluation/paid capabilities include timestamp-window replay, DLQ redrive, same-topic/cross-profile recovery, offset reset, agent proposals and larger allowances as licensed.

Report suspected vulnerabilities privately using [SECURITY.md](SECURITY.md), not a public issue. This repository is for distribution tooling/documentation; do not expect private application source access.
